# Orchestrator IAM v2.5.1

This maintenance release updates the Go toolchain and dependencies while
preserving the v2.5.0 identity, authorization and database contracts.

## Security and compatibility

Official builds use Go 1.26.10, including the certificate verification fix for
[CVE-2026-111943](https://pkg.go.dev/vuln/GO-2026-6809). HTTP, cryptography,
OpenAPI and telemetry dependencies are updated.

Membership reference descriptions use valid OpenAPI composition. JSON fields,
identity semantics and permissions are unchanged. The SDK source now requires
Go 1.26.10; its module tag is published separately from the application tag.

Normal CI checks source dependencies and both the compiled server and
authorization migration tool for reachable known vulnerabilities. Release
binaries retain linker symbols for this scan; DWARF debug information remains
omitted. Docker build contexts exclude direnv and local environment state.
The self-hosted SSO fixture uses digest-pinned Keycloak 26.8.1.

## Upgrade and recovery

The coordinated application patch set is Control Plane 3.1.1, Data Plane 4.0.1,
IAM 2.5.1 and Console 1.4.1. Use verified public artifacts for the selected set.
This patch adds no database migration. Back up the IAM database and configuration
before upgrading. Retain the v2.5.0 schema and recover with a compatible
application revision or forward repair, rather than database Down migrations.

A Keycloak server upgrade is a separate database migration. Back up and test
snapshot recovery before upgrading it; Helm rollback alone cannot restore the
old Keycloak database. This IAM patch does not update external services or
clear the separate Runner and plugin runtime security holds.
