# IAM 2.8.0

PostgreSQL transport security is configurable through `DATABASE_SSLMODE`. The default remains `disable`; set `require` to enforce encryption without plaintext fallback, or `verify-full` with `PGSSLROOTCERT` to verify the server certificate and hostname. The existing driver handles certificate settings and rejects invalid modes during database initialization.

Connection-string values are quoted correctly, including spaces, quotes and backslashes in credentials or database names. Startup and automatic migrations use the same connection string. The separate authorization migration command retains its existing explicit database URL precedence and `DATABASE_SSLMODE` support.

No database migration or authentication/session behavior change is introduced. Restart IAM after changing database startup settings.
